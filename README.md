# Galaxy Imaging Technologies

Next.js version of the Galaxy Imaging website.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Pages

- `/` Home
- `/about`
- `/solutions`
- `/products` and `/products/[slug]`
- `/services`
- `/industries`
- `/blogs`
- `/news`
- `/careers`
- `/support`
- `/contact` opens the quote popup from any Contact / Get a Quote link
